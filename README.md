# Surviving-The-Spiral-Feedback

Bug reports, compatibility issues, and feedback for the **Surviving The Spiral** Minecraft modpack.

## About

Welcome to the official feedback and issue tracker for **Surviving The Spiral**!

Use this repository to report bugs, crashes, compatibility problems, performance issues, or suggest improvements for the modpack.

## How to Report an Issue

Click the **Issues** tab and select **New issue**. Choose the template that best matches your report.

- **Bug Report:** Unexpected behavior or broken gameplay features.
- **Crash Report:** Game crashes or failures to launch.
- **Compatibility Report:** Mod conflicts or version compatibility problems.
- **Performance Report:** Low FPS, lag, or stuttering.
- **Feature Request:** Ideas for new features or future improvements.

## Before Submitting

- Make sure you're using Minecraft **1.21.1**, the version the modpack was made for.
- Include your Surviving The Spiral version and NeoForge version.
- Check whether the issue has already been reported.
- Describe the steps needed to reproduce the problem.
- Include relevant crash reports or logs when possible.
- Mention any mods you've added, removed, or updated.

**Important:** Reports involving unsupported Minecraft versions or modified modpack installations may not be reproducible with the official modpack.

## Suggestions and Feedback

Suggestions are welcome! However, not every suggestion will necessarily be implemented. New mods and features must fit the modpack's goals and remain compatible with its existing setup.

Thanks for helping improve **Surviving The Spiral**!
